# Методички ДезТехЮг CRM

Документация по работе с CRM-системой. Структура — общая часть + три ролевые методички.

## Содержание

| Документ | Для кого | Объём |
|---|---|---|
| [00-general.md](./00-general.md) | Все роли | Общие инструменты, Telegram, профиль, термины |
| [01-admin.md](./01-admin.md) | Администратор (Саня) | Юзеры, услуги, шаблоны, удаления, настройки |
| [02-manager.md](./02-manager.md) | Менеджер (Регина) | Лиды, клиенты, сделки, документы, отчёты |
| [03-master.md](./03-master.md) | Мастер (Александр) | Мои выезды, журнал работ, запросы переноса |

## Скриншоты

В папке [`../screenshots/`](../screenshots/) — снимки всех страниц CRM. Делались автоматически через `scripts/take-screenshots.ts` (Playwright). Для обновления:

```bash
# 1. Подними dev-стек
npm run docker:dev:up
npm run dev

# 2. Запусти скрипт (займёт 2-3 минуты)
npx tsx scripts/take-screenshots.ts
```

## Как читать методички

1. **Сначала общую** [00-general.md](./00-general.md) — там основы, без неё ролевые покажутся непонятными.
2. **Потом свою ролевую** — admin / manager / master.
3. Каждая методичка устроена одинаково: «Содержание» → описание разделов CRM → раздел «Сценарии» в конце с типовыми задачами.

## Когда обновлять

При **больших изменениях** в Sprint'ах, особенно если:
- Появились новые страницы / разделы
- Поменялись права роли
- Добавились новые типы документов / стадий лида
- Изменились пороги / настройки по умолчанию

Скриншоты тоже надо переснять (см. выше).

## Альтернатива: страница `/manual` в CRM

Сейчас методички — markdown в репо. В будущем (Sprint 6+) можно сделать страницу `/manual` в CRM которая render'ит этот markdown через `react-markdown`. Тогда методички будут доступны прямо из меню сайдбара, без открытия GitHub.
